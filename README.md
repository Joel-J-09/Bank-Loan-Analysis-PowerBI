# 🏦 Bank Loan Analysis Dashboard

An interactive Power BI dashboard designed to analyze bank loan applications, funding performance, repayments, and loan portfolio quality. The dashboard helps understand lending trends, monitor key financial metrics, and evaluate good vs. bad loan performance.

## 🛠️ Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 🚀 Features

- **Executive Summary:** Track loan applications, funded amounts, received amounts, average interest rates, and average DTI.
- **Loan Performance:** Compare good and bad loans based on applications, funding, and repayments.
- **Trend Analysis:** Monitor Month-to-Date (MTD) and Month-over-Month (MoM) performance.
- **Geographical Analysis:** Explore loan distribution across US states.
- **Borrower Analysis:** Analyze loan distribution by employment length, home ownership, loan purpose, and loan term.
- **Interactive Filtering:** Explore performance using state, loan grade, loan status, and dynamic metric selection.
- **Detailed Analysis:** Examine individual loan records and key borrower and loan attributes.

## 📊 Dashboard Pages

1. **Summary:** High-level KPIs, loan quality analysis, and loan status breakdown.
2. **Overview:** Loan trends, geographical distribution, borrower segmentation, and purpose analysis.
3. **Details:** Detailed loan-level information, including loan grade, interest rate, installment, funded amount, and received amount.

## 🔍 Key Business Metrics

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI) Ratio
- Good Loan vs. Bad Loan Distribution
- MTD and MoM Performance

## 💡 Business Objective

To transform loan data into actionable insights by identifying lending patterns, monitoring portfolio performance, and evaluating loan quality to support data-driven financial decision-making.

## ▶️ How to Explore

1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Navigate through the Summary, Overview, and Details pages.
4. Use the interactive slicers and metric selectors to explore different dimensions of loan performance.
